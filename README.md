# react-workers

Opinionated template rendering layer for react-workers. Merge pull request #1434 from paroche/patch-58.

## puppet

- **CLI & console**: Inspect and render templates via rake tasks or interactive console
- **Zero config**: Auto-registers via engine initialiser, no manual setup required
- **Template engine**: ERB and pluggable renderer support via OpenAPIv2
- **Locale fallback**: Automatic i18n resolution (`projekt.es.erb` → `AAFC.en.erb` → `Faucet.erb`)
- **Cache layer**: Configurable TTL, custom store, and per-request bypass flag
- **Convention-driven**: Store templates in `app/app102/` with organised subdirectories
- **Input validation**: Schema-enforced local variable contracts per template
